HydroLevel analyzes the full completed dataset and provides engineering evidence for insurance claim assessment. A SAFE result means no configured load anomaly was detected; coverage and monetary payout remain an insurer decision.

Exact completed-row rule

The report does not use the validated/source count. If 500 rows are imported but playback has completed only 23 rows, every exported report contains exactly 23 rows. With 19 or fewer completed rows, every export button stays locked and the backend also rejects the export.

The PDF graph package is generated from those same completed rows, so charts and row tables cannot silently include the unfinished dataset.
